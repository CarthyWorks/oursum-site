# oursum-site

Static marketing/landing page for [Oursum](https://github.com/teomurgi/our-expenses) — a private, offline-first expense tracker for macOS.

## What's in here

A single self-contained `index.html` (no build step, no dependencies) with two icon assets:

| File | Description |
|---|---|
| `index.html` | Landing page — features, download section, screenshots |
| `icon_128x128.png` | App icon (128 px) |
| `icon_32x32.png` | App icon / favicon (32 px) |

## Deployment

The site is intended to be served as a static page (e.g. GitHub Pages). No build toolchain required — just serve the root directory.
