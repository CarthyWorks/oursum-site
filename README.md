# oursum-site

Static landing page for [Oursum](https://github.com/CarthyWorks/oursum) — a private, offline-first expense tracker for macOS.

🌐 **Live site:** https://oursum.app

## What's in here

A single self-contained `index.html` (no build step, no dependencies):

| File | Description |
|---|---|
| `index.html` | Landing page — features, how it works, download, contribute |
| `icon_128x128.png` | App icon (128 px) |
| `icon_32x32.png` | App icon / favicon (32 px) |
| `social-preview.svg` | Social preview image source (1200×630) |
| `social-preview.png` | Social preview image rendered (1200×630, used by OG/Twitter meta) |

## Deployment

Served as a static page via GitHub Pages from the `main` branch root. No build toolchain required.
